# ⚡ 인스레드 치트 (InThread Cheat) v1.0.0

스레드(Threads)에서 반응 좋은 쇼핑·추천·바이럴 피드를 **1클릭으로 레퍼런스(본문 + 고화질 이미지 + 링크)**하고, AI 후킹 스타일로 변환하여 **내 스레드에 바로 업로드**할 수 있는 크롬 확장프로그램입니다.

---

## 🚀 주요 기능

1. **내장 온보딩 대시보드 (`onboarding.html`)**
   - 확장 프로그램 설치 시 자동으로 열리는 전용 시작 가이드 대시보드
   - **Step 1**: Threads 계정 브라우저 로그인 세션 실시간 확인 (`@username` 연결)
   - **Step 2**: 쿠팡 파트너스 Sub ID 설정 및 실시간 링크 변환 시뮬레이터
   - **Step 3**: 3초 마스터 워크플로우 튜토리얼 (피드 발견 ➔ AI 후킹 변환 ➔ 바로 올리기)
   - 팝업 우측 상단의 `[💡]` 아이콘을 누르면 언제든 다시 온보딩 대시보드를 열 수 있습니다.

2. **스레드 피드 원클릭 레퍼런스**
   - 스레드 웹(`threads.com`) 탐색 중 피드 하단에 **`[⚡ 치트 레퍼런스]`** 플로팅 버튼 자동 표시
   - 클릭 한 번으로 본문 텍스트, 캐러셀 전체 고화질 이미지, 원문 작성자 및 링크 자동 추출 & 저장
   - 쇼핑·할인·공구 키워드 감지 시 `🛍️ 쇼핑/추천 피드` 배지 자동 표시

3. **⚡ 퀵 치트 스튜디오 (내 스레드로 바로 발행)**
   - **AI 후킹 카피 변환 엔진**:
     - 🔥 **호기심 유발형**: "이거 왜 아무도 안 알려줬지?", "삶의 질 3배 상승..." 등 클릭률 극대화 스타일
     - 💡 **리얼 찐후기형**: 내돈내산 3주 차 솔직 장단점 후기 스타일
     - ⚡ **마감/할인 특가형**: "역대급 할인 떴습니다" 품절 임박 분위기 연출
     - 📌 **3줄 핵심 요약형**: 가독성을 높인 3줄 요약 스타일
   - **내 스레드 즉시 발행**:
     - 클릭 시 Threads 글쓰기 창으로 즉시 연결 및 클립보드 복사 자동 주입 (Ctrl+V로 바로 완료)
   - **예약 발행 큐**:
     - 원하는 시간(분 단위) 뒤에 자동 백그라운드 발행 스케줄링 지원

4. **쿠팡 파트너스 & 쇼핑 링크 치트 도구**
   - 레퍼런스 피드에 포함된 쿠팡/스마트스토어 링크를 내 쿠팡 파트너스 Sub ID가 적용된 링크로 즉시 변환
   - 팝업 내 쿠팡 링크 변환기 내장

5. **100% 로컬 독립 동작 (서버 로그인 불필요)**
   - 기존 하입덕 서버(hypeduck.ai) 인증 종속성을 완전히 제거하여 별도의 유료 결제나 외부 로그인 없이 브라우저 로컬(`chrome.storage.local`)에서 완전 무료/독립적으로 작동합니다.

## 📦 크롬 브라우저 설치 방법

1. Chrome 브라우저를 열고 주소창에 `chrome://extensions` 입력 후 이동
2. 우측 상단의 **'개발자 모드 (Developer mode)'** 스위치를 **ON**으로 켭니다.
3. 좌측 상단의 **'압축해제된 확장 프로그램을 로드합니다'** 버튼 클릭
4. 아래 폴더를 선택합니다:
   ```
   C:\Users\hynihk\Documents\하입덕\dist
   ```
5. 설치 즉시 **인스레드 치트 온보딩 대시보드** 탭이 자동으로 열립니다!
6. [https://www.threads.com](https://www.threads.com)에 접속하여 스레드 피드에서 `[⚡ 치트 레퍼런스]` 버튼을 사용해보세요.
