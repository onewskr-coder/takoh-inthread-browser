# 전용 브라우저 시험판

실행: 이 폴더의 start-browser.bat 또는 npm start.

Threads, Instagram, Pinterest와 기존 로컬 제작 화면(127.0.0.1:5006/studio)을 탭으로 전환합니다. 앱은 전용 도우미의 연결을 확인하고 필요하면 로컬 Python으로 시작합니다. 일반 Chrome과 다른 로그인 세션을 사용합니다.

현재 단계: 사이트 코드 연결 및 도우미 시작·준비 상태 관리 구현. 실제 수집부터 제작 화면 전달까지의 검증, 게시 준비, 도우미 자체 포함 배포는 미완료입니다. 기존 확장과 사용자 데이터는 보존합니다.

최종 목표와 단계별 완료 기준: [DEVELOPMENT-GOALS.md](DEVELOPMENT-GOALS.md).
