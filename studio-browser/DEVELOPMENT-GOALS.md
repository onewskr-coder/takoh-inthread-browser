# 타코 · 인스레드 치트키 전용 앱 개발 목표

수립일: 2026-10-12

## 최종 목표

Threads·Instagram·Pinterest에서 콘텐츠를 수집·다운로드하고, 같은 앱에서 원본 분석·영상 편집·상품 및 제휴 링크 연결·Threads 글 작성을 진행한 뒤 실제 작성창에 게시를 준비하는 전용 앱을 완성한다. 도우미와 필요한 실행 환경은 앱에 포함해 별도로 설치하거나 실행하지 않아도 되게 한다. 기존 사용자 데이터와 Chrome 확장은 보존한다.

기본 게시 방식은 실제 작성창에 영상·본문을 입력하고 사용자가 최종 게시하는 반자동 방식이다. 첫 댓글에는 #광고, 해당 제휴 프로그램의 경제적 이해관계 고지, 클릭 유도 문구와 제휴 링크를 준비한다. API 없이 게시하는 선택을 제공하되 노출 증가나 쉐도우밴 방지를 보장하지 않는다.

## 단계별 목표와 완료 증거

| 단계 | 목표 | 완료를 증명할 실제 결과 |
|---|---|---|
| G1 실행 기반 | 단일 앱 실행, 로그인 세션 유지, 도우미 자동 시작·준비 대기·실패 안내·안전한 종료 처리 | 세 사이트 로그인 후 앱 재시작, 중복 실행, 도우미 미실행·포트 점유·종료 상황을 확인. 기존 프로세스나 작업을 강제 종료하지 않음 |
| G2 소스 확보 | 세 사이트의 게시물·검색·프로필·릴스 및 슬라이드에서 개별 수집·저장, 실제 캐러셀에만 전체 저장 | 플랫폼별 새 콘텐츠를 UI에서 선택해 정확한 이미지/영상 저장. 영상 재생과 음성 확인. 스크롤·슬라이드 전환 후 버튼 위치·중복 확인. 로그인·프로필 사진·작성창에는 버튼 없음 |
| G3 보관함 | 주소·썸네일·원본 파일·저장 위치 연결, 중복 방지, 선택·삭제·재사용 | 수집 및 다운로드 자료가 같은 보관함에 표시. 재시작 후 유지. 선택하면 분석에 정확한 원본 전달. 링크 입력만으로 준비 가능. 삭제 범위를 명확히 표시하며 원본을 무단 삭제하지 않음 |
| G4 분석과 글 | 설정의 CLI/API·모델·사용량, 원본 분석 보존, 사용자 스타일, 초안 3개 | 실제 신규 콘텐츠 분석 결과 저장·재시작·재사용. 줄바꿈된 500자 이하 초안 3개 생성·선택. 모델 권한/할당량 실패와 승인된 대체 모델 처리. 알려진 사용량과 추정치 구분 |
| G5 영상 편집 | 추천 후킹 장면 이동, 제품 중심 효과, 음성 제거, 자막/워터마크 처리, 광고 표시 | 원본 보존 및 별도 MP4 출력. 후킹 구간 중복·누락 없음. 효과·초점·음성·광고 위치를 출력에서 확인. 자막 처리 진행률과 미리보기 제공. 복원 결과가 불완전하면 이를 표시 |
| G6 상품·제휴 | 원본 프레임/이미지와 비교하는 상품 검색, 사용자 일치 확인, 링크 수동 입력 및 가능한 API 발급 | 실제 원본으로 후보 검색, 선택한 상품과 제휴 링크 저장·재로드. API 미등록/발급 실패 시 직접 입력 가능. 쿠팡파트너스·네이버 쇼핑커넥트·토스쇼핑·아마존의 지원 범위를 명시 |
| G7 반자동 게시 | 실제 Threads 작성창의 영상·본문·첫 댓글 준비, 사용자가 최종 게시 | 사용자 승인 콘텐츠가 정확히 입력되고 첨부 업로드 완료. 사용자가 본문·댓글 게시 후 실제 게시 주소와 상태 기록. 공개 테스트 게시는 사용자가 지정한 콘텐츠로만 수행 |
| G8 예약과 복구 | 우선 예약 준비·알림, 작업 이력·취소·재시작 복구·중복 게시 방지 | 예약 도래, 앱 종료/재실행, 로그인 해제, 취소, 응답 불명확 상황 확인. 성공 불명확 시 자동 재게시하지 않음. 완전 자동/API 예약은 별도 선택 기능으로 검증 후 제공 |
| G9 설치와 유지관리 | 도우미·실행 환경 포함, 업데이트·로그·데이터 보존 | Python·확장 별도 설치 없는 새 Windows 환경에서 실행. 업데이트 후 로그인/보관함/설정 보존. 배포본으로 수집부터 게시 준비까지 재검증 |

## 현재 상태 — 코드와 실제 동작 구분

2026-10-12 소스 확인 기준:

- 사이트 탭, 기존 제작 화면 연결, 사이트 코드 주입, 수집 IPC 및 도우미 보관함 API 호출 경로가 존재한다.
- `helper-manager.cjs`에 API 준비 확인, 기존 서버 재사용, 시작 실패 상태 관리가 있다. `main.cjs`에 단일 앱 실행 및 상태 조회 연결이 있다.
- 전용 앱용 도우미는 127.0.0.1:5006을 사용한다. 기존 Chrome 도우미와 별도로 취급한다.
- 세 플랫폼의 수집·다운로드·보관함 전달을 끝까지 검증한 증거는 아직 없다. 단계 완료로 표시하지 않는다.
- 도우미는 현재 로컬 Python과 소스 파일에 의존한다. 자체 포함 배포는 미완료다.
- Google의 내장 브라우저 로그인 제약은 미해결이며 우회하지 않는다. Pinterest QR 로그인 후 세션 유지 검증이 필요하다.

## 우선순위와 출시 기준

G1 → G2 → G3을 먼저 완료하고, 이후 G4 → G5 → G6 → G7 → G8 → G9 순서로 진행한다. 소스 확보 경로가 실제로 작동하기 전에는 새로운 기능 확장보다 해당 경로의 실패 해결을 우선한다.

첫 사용 가능 시험판의 기준: 세 플랫폼에서 각각 사용자 선택 신규 콘텐츠의 수집 → 정확한 파일 저장 → 썸네일 보관함 → 원본 분석 전달을 UI로 완료하고 재시작 후에도 재사용할 수 있다.

최종 출시 기준: 위 G1~G9 완료 증거를 남기고 새 Windows 환경의 배포본에서 전체 흐름을 검증한다. 코드가 있거나 단위 테스트가 통과했다는 이유만으로 사용자 작업 완료를 선언하지 않는다.

## 검증 및 작업 원칙

- 플랫폼별 이미지·영상·혼합 캐러셀·동적 로딩을 구분해 기록한다. 일반 클릭은 다운로드를 일으키지 않아야 한다.
- 검증은 코드/테스트, 실제 브라우저 화면, 저장 파일 재생·음성, 전체 작업 흐름으로 구분한다. 미검증과 접근 제한은 별도로 기록한다.
- 실제 결제형 API 호출과 공개 게시 테스트는 사용자 승인 범위에서 수행한다.
- 기존 사용자 데이터와 실행 중인 다른 도우미를 보존한다. 테스트 데이터는 격리한다.
- 개발 중 매번 EXE나 ZIP을 만들지 않는다. 배포본 제작은 출시 요청 단계에서 수행한다.
- 계정 제한·게시 실패·성공 불명확 상태는 사용자에게 표시하고 인증 우회나 무조건 재시도를 하지 않는다.
