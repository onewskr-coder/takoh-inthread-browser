# Project handoff rules

- Read CURRENT-STATE.md and ANTIGRAVITY-START.md before changes.
- Preserve existing user profiles, cookies, saved references, jobs, and secrets. Never commit them.
- Do not terminate an existing helper/port owner without explicit user approval.
- Do not build EXE/ZIP routinely; use source development workflow.
- Keep static/unit, real browser, saved media/audio, paid provider, and distribution evidence separate.
- Do not claim end-to-end completion without a new user-selected source completing through the UI.
- Keep auto restart disabled until login preservation and process ownership are verified.
- Deliver HANDOFF-RESULT.md after each bounded task. Codex supplies directions; Antigravity implements and verifies.
