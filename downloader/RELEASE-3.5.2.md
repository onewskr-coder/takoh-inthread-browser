# 인스레드 치트키 by TAKOH 3.5.2

- 레퍼런스 카드 DOM과 CSS 클래스 연결을 수정했습니다. 썸네일 영역은 높이 200px로 고정하며 세로 영상은 비율을 유지합니다. 좁은 화면은 한 열, 넓은 화면은 여러 열로 표시합니다.
- Pinterest 원본 준비에서 지역 도메인을 canonical 핀 주소로 정규화하고 기존 Pinterest 구조화 데이터 추출기를 연결했습니다. 추출 실패를 삭제된 게시물로 단정하지 않습니다.
- Pinterest 수집은 실제 미디어가 속한 핀 ID를 사용하며 blob 영상의 구조화 MP4와 원본 썸네일을 함께 저장합니다.
- Pinterest 수집/다운로드 컨트롤 배치는 페이지 전역의 저장·뒤로가기 버튼 위치를 고려하고 미디어 하단 배치부터 시도합니다.

검증: Python 50개 및 JavaScript 13개 테스트 통과. 브라우저에서 0단계 카드 한 열/두 열 및 원본 준비 후 1단계 이동을 확인했습니다. Pinterest 300404237670215552의 실제 영상은 720×1280, 29.3초이며 음성 트랙을 포함합니다. 설치된 Chrome 확장 프로그램의 실제 피드 버튼 배치는 이번 검증에 포함하지 않았습니다.
