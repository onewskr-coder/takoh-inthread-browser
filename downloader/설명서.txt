3. ⚡ 확장프로그램 안정성 및 통신 강화
   - 크롬 확장 프로그램 재로드 시 연결 끊김 방지(안전 통신 래퍼) 적용
   - 크롬 확장 프로그램 로드 시 시스템 폴더 충돌 원인 파일 완전 배제
------------------------------------------------------------

TAKOH Media Downloader PRO 확장프로그램을 이용해 주셔서 감사합니다.
본 프로그램은 쓰레드, 인스타그램, 페이스북, 틱톡, X(Twitter), 핀터레스트, 네이버 클립,
쿠팡, 유튜브 및 쇼츠 등 다양한 플랫폼의 미디어를 단 한 번의 클릭으로
쉽고 빠르게 최고 해상도로 PC에 저장할 수 있도록 지원합니다.

------------------------------------------------------------
1. 크롬 확장프로그램 설치 및 라이센스 활성화 방법
------------------------------------------------------------
① 구글 크롬(Chrome) 브라우저를 실행합니다.
② 주소창에 [ chrome://extensions ] 를 입력하여 확장프로그램 관리 화면으로 이동합니다.
③ 우측 상단의 [개발자 모드] 토글을 켜서 활성화합니다.
④ 좌측 상단의 [압축해제된 확장 프로그램을 로드합니다] 버튼을 클릭합니다.
⑤ 본 압축 파일 내의 [TAKOH_확장프로그램] 폴더를 통째로 선택하여 로드합니다.
⑥ 설치 후 크롬 툴바의 퍼즐 아이콘을 눌러 [TAKOH Media Downloader PRO]를 고정합니다.
⑦ 확장프로그램 아이콘(사이드바 대시보드)을 열어 구매 시 등록하셨던 
   [이메일 주소] 또는 [휴대폰 번호(010-XXXX-XXXX)]를 입력하고 [활성화] 버튼을 누릅니다.
   - 최초 활성화 시 나만의 라이센스 시리얼키가 자동 발급되며, 24시간 동안 오프라인 상태에서도 초고속 인증 유예(캐시)가 연계 적용됩니다.
   - 대시보드 내 [기기 등록 해제] 버튼 클릭 시, 구글 서버 시트 슬롯 반환 처리가 즉시 이루어져 다른 PC에서 자유롭게 재활성화가 가능합니다.
   - 하나의 구매 정보당 기기 대수 제한 없이 자유롭게 무제한으로 등록 및 사용이 가능합니다.

2. 플랫폼별 사용 방법 & 유용한 기능 설정
------------------------------------------------------------
■ 화질 기본 설정
   - 팝업 대시보드를 열면 "동영상 기본 화질 설정" 메뉴가 있습니다.
   - [최고 화질 (1080p~4K 이상)], [720p], [480p] 중 원하시는 다운로드 화질을 선택할 수 있습니다.

■ 저장할 폴더 항상 물어보기 (폴더선택)
   - 사이드바 설정 영역의 "저장할 폴더 항상 물어보기" 스위치를 켜면, 다운로드 버튼을 누를 때마다 파일 탐색기(윈도우/맥 기본 대화상자)가 자동으로 팝업되어 원하는 로컬 저장 폴더와 파일명을 자유롭게 마우스 클릭으로 선택해 저장할 수 있습니다.


■ Instagram (인스타그램)
   - 피드/게시글 내 이미지 및 비디오 위에 전용 버튼이 생성됩니다.
   - 특히 여러 장의 사진/동영상이 슬라이드 형식으로 올라온 멀티 포스트의 경우, 버튼 옆에 초록색 [모두 저장 (갯수)] 버튼이 자동 활성화되어 단 한 번의 클릭으로 묶음 미디어를 250ms 간격 순차 큐를 통해 일괄 저장할 수 있습니다.
   - 스토리(Stories) 뷰어 화면에서도 원본 추출 및 상단 다운로드 버튼 배치를 전면 지원합니다. (※ 글쓰기 작성 팝업창에서는 사용 편의상 오작동 방지를 위해 다운로드 버튼 마운트가 제외됩니다.)

■ Pinterest (핀터레스트)
   - 핀 이미지 피드나 상세 페이지에서 우측 상단에 노출되는 다운로드 버튼을 클릭하면, 썸네일 경로를 자동으로 감지 분석해 워터마크 없는 100% 원본 초고화질 이미지(originals)로 치환되어 다운로드됩니다.

■ Threads, Facebook, TikTok, X(Twitter), 네이버 클립, 쿠팡
   - 각 사이트 미디어 카드 혹은 재생 화면 위에 배치되는 깔끔한 원본 다운로드 버튼을 누르면
     IP 차단 및 워터마크 없이 깔끔한 원본 MP4/이미지 파일이 PC로 다운로드됩니다.

■ YouTube & Shorts (유튜브 및 쇼츠)
   - 구글의 강력한 데이터센터 IP 차단 정책 우회를 위해 별도로 제공되는 "로컬 도우미 프로그램" 가동이 필요합니다.

3. 유튜브 우회용 로컬 도우미 가동 방법
------------------------------------------------------------
유튜브 영상 다운로드를 하려면 아래 순서대로 로컬 도우미 프로그램을 가동해 주세요.
(※ 파이썬이 설치되어 있지 않은 사용자도 무설치로 바로 가동할 수 있도록 원클릭 실행파일을 전면 지원합니다.)

[윈도우(Windows) 사용자의 경우]
① 제공된 [TAKOH_도우미프로그램] 폴더로 이동합니다.
② 폴더 안에 있는 [start_helper.bat] 파일을 더블 클릭하여 실행합니다.
   - 파이썬이 설치되어 있다면 로컬 Flask 서버 환경을 알아서 구축하여 구동하고,
   - 파이썬이 없는 환경이라도 포함되어 있는 [TAKOH_Helper.exe]를 감지하여 무설치 패키지로 즉시 자동 구동합니다.

[맥(macOS) 사용자의 경우]
① 제공된 [TAKOH_Helper] 폴더로 이동합니다.
② 폴더 안에 있는 [start_helper.command] 파일을 마우스 더블 클릭하여 실행합니다.
   - ⚠️ "적절한 접근 권한이 없기 때문에..." 또는 실행 차단 에러창이 뜨는 경우:
     Mac은 인터넷에서 다운로드받은 파일에 보안 제한(Quarantine)을 둡니다. 최초 1회만 맥 [터미널] 앱을 열어 아래 1줄을 복사해서 붙여넣고 엔터를 치면 해결됩니다:
     
     xattr -cr ~/Downloads/TAKOH_Media_Downloader_PRO_v3.0.6 && chmod +x ~/Downloads/TAKOH_Media_Downloader_PRO_v3.0.6/TAKOH_Helper/start_helper.command

   - ※ 보안 경고창("확인되지 않은 개발자")이 뜨는 경우: [start_helper.command] 파일 우클릭(또는 Control + 클릭) -> [열기] -> [열기]를 누르시면 즉시 구동됩니다.
   - ※ 만약 맥에 파이썬(Python3)이 미설치된 상태인 경우, 화면 안내에 따라 https://www.python.org/downloads/ 에서 macOS용 파이썬을 한 번만 설치 후 더블 클릭하시면 바로 구동됩니다.

③ 검은색 터미널 창에 "로컬 도우미 서버 가동 성공" 또는 "Running on http://127.0.0.1:5005"가 표시되면 정상 연결 상태입니다.
④ 유튜브 동영상을 다운로드하는 동안에는 이 실행 창(터미널 창)을 닫지 말고 켜두세요.
⑤ 확장프로그램 팝업 창 하단의 [로컬 도우미 연결 테스트] 상태가 초록색(연결됨)으로 켜져 있으면, 유튜브 비디오 영역 상단에 노출되는 다운로드 버튼을 눌러 최고 사양으로 즉시 내려받을 수 있습니다.
