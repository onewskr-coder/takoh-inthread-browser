## v3.1.9 — 2026-10-08

- 모든 기존 미디어 오버레이를 실제 사진·영상 요소에 연결하는 공통 배치 기능 적용. 게시물 헤더 대신 보이는 미디어 영역의 상단 경계를 사용.
- 상단의 기존 버튼과 겹치면 반대편 또는 아래쪽 상단 행 선택. 좁은 카드에서는 아이콘·툴팁·접근성 이름을 유지하고 텍스트를 접음.
- 스크롤·크기 변경·전체화면·주기 검사에 위치 갱신, 화면 밖·캐러셀 클리핑·제거된 미디어의 버튼 숨김.
- 모든 플랫폼에서 좌표만으로 클릭을 가로채던 방식 대신 실제 다운로드 버튼 클릭만 처리.
- 실제 Threads/Pinterest 미디어 경계 확인 및 로컬 브라우저 배치 스크린샷 확인. 로그인·접근 제한 사이트의 설치 확장 실화면은 미검증.

## v3.1.8 — 2026-10-08

- 쿠팡: 영상 버튼은 리뷰 첨부·리뷰 갤러리 안의 플레이어로 제한. 갤러리 선택 버튼에서도 프로필 이미지 제외.
- 네이버: 리뷰 미디어 영역 및 리뷰 첨부 주소로 확인된 사진에 이미지 버튼 추가. 쇼핑 페이지 영상은 리뷰 영역으로 제한하고 탐색 UI·광고 영역 제외.
- 네이버 클립 영상 버튼 유지. 쿠팡·네이버 공통 클릭 처리는 실제 다운로드 버튼 대상으로 제한하여 일반 클릭의 오작동 방지.
- 리뷰/클립 DOM 및 일반 클릭 회귀 테스트 통과. 실제 리뷰 페이지 다운로드는 미검증.

## v3.1.7 — 2026-10-08

- Instagram·Threads: 고해상도 원본을 가진 작은 아바타, 프로필 링크 및 프로필 전용 CDN 이미지에 다운로드 버튼을 붙이지 않도록 보완.
- Threads 이미지는 게시물 경계가 확인된 콘텐츠에만 버튼 표시. Instagram 묶음 저장에도 같은 프로필 필터 적용.
- Pinterest·샤오홍슈·Reddit·쿠팡 이미지 스캐너에 공통 아바타·탐색 UI 필터 적용.
- 공통 이미지 필터 및 Threads 실제 모듈 DOM 회귀 검증 통과. 설치된 확장 프로그램의 실제 사이트 클릭은 별도 확인 필요.

## v3.1.6 — 2026-10-08

- Threads: 콘텐츠 내부 버튼을 body의 고정 컨트롤로 이동하고 스크롤·캐러셀 클리핑·콘텐츠 제거에 맞춰 위치 및 표시 상태를 갱신.
- 프로필 링크와 게시물 미디어 링크를 구분하여 피드 이미지 누락 방지. 이미지 클릭 시 해당 이미지 주소만 사용.
- 영상은 해당 video 요소의 주소를 우선 사용하고 다른 피드 영상의 최신 네트워크 주소로 대체하지 않음.
- 이미지 Blob의 MIME을 image로 유지. 게시물 경계에서 파일명 작성자·게시물 ID 추출.
- 실제 Threads 피드 영상 1개(720x1280, 86.38초, AAC 포함) 및 JPEG 이미지 1개 다운로드·전체 디코딩 확인.
