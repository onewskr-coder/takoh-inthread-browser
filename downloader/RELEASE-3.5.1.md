# 인스레드 치트키 by TAKOH 3.5.1

- 영상 요청에 이미지가 반환되면 실패로 표시하며 이미지 작업으로 바꾸지 않습니다.
- 확장 다운로드 목록과 도우미 썸네일을 절대 경로로 연결합니다. 같은 이름의 다른 파일도 유지합니다.
- 보관함의 제작 버튼은 0단계로 이동합니다. 사용할 미디어를 선택하고 원본을 준비하면 분석 단계로 이동합니다.
- 원본 획득 실패 메시지, 원본 주소와 미디어 선택을 목록 갱신 중 유지합니다.
- 사용자 모델은 미확인으로 저장합니다. API 계정 모델 목록 갱신은 입력한 API 키로 공급자 목록을 조회하며 키를 저장하지 않습니다. CLI 모델 권한은 공식 CLI에서 확인합니다.

검증: Python 49개 및 JavaScript 12개 테스트 통과. 외부 사이트의 실제 다운로드와 실제 AI 분석 호출은 이번 회귀 테스트에 포함하지 않았습니다.

설치: 기존 도우미를 종료하고 3.5.1 ZIP을 새 폴더에 풉니다. 새 TAKOH_Helper/start_helper.bat을 실행하고 확장 프로그램을 새 TAKOH_Extension 폴더에서 로드한 뒤 사이트와 제작 화면을 새로고침합니다.
