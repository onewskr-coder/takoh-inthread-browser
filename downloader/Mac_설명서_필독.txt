============================================================
       🍏 [필독] Mac(macOS) 전용 TAKOH 도우미 실행 안내서
============================================================

TAKOH Media Downloader PRO를 이용해 주셔서 감사합니다.
맥(macOS) 환경에서 유튜브/쇼츠 다운로드용 로컬 도우미 프로그램(start_helper.command)을
처음 실행할 때 발생하는 맥 보안 차단을 10초 만에 해결하는 안내서입니다.

------------------------------------------------------------
🚨 맥(macOS) 사용자가 필독해야 하는 이유!
------------------------------------------------------------
Mac OS는 인터넷(카카오톡, 사파리, 크롬 등)에서 다운로드받은 파일에
자동으로 [보안 격리(Quarantine) 태그]를 부여하여 실행을 차단합니다.

이로 인해 더블 클릭 시 아래와 같은 경고창이 발생합니다:
- "적절한 접근 권한이 없기 때문에 'start_helper.command' 파일을 실행할 수 없습니다."
- "'start_helper.command'을(를) 열지 않음 (Apple은 악성 코드가 없음을 확인..."

👉 다운로드 후 [최초 1회만] 아래 순서대로 보안을 해제해 주시면
   그 이후부터는 매번 더블 클릭만으로 100% 정상 구동됩니다!

------------------------------------------------------------
⚡ [최초 1회] 10초 해결 방법 (따라하기)
------------------------------------------------------------

① 맥의 [터미널] 앱을 엽니다.
   - 키보드의 [Command(⌘) + 스페이스바]를 눌러 Spotlight 검색창을 엽니다.
   - '터미널' 또는 'terminal'을 입력하고 엔터를 칩니다.

② 아래 [1줄 명령어] 전체를 복사해서 터미널 창에 붙여넣고 [엔터(Enter)]를 칩니다:

xattr -cr ~/Downloads/TAKOH_Media_Downloader_PRO_v3.1.0 && chmod +x ~/Downloads/TAKOH_Media_Downloader_PRO_v3.1.0/TAKOH_Helper/start_helper.command

   ※ 압축을 [다운로드(Downloads)] 폴더에 해제했을 때의 기본 경로입니다.
   ※ 다른 폴더에 해제하셨다면 터미널에 `xattr -cr `을 입력한 후 해제한 TAKOH_Media_Downloader_PRO_v3.1.0 폴더를 터미널로 끌어다 놓으시면 됩니다.

③ 이제 [TAKOH_Helper] 폴더 안의 [start_helper.command] 파일 아이콘을 마우스 더블 클릭합니다.

④ 검은색 터미널 창이 열리며 "Running on http://127.0.0.1:5005" 문구가 뜨면 성공입니다!

------------------------------------------------------------
💡 추가 참고 사항
------------------------------------------------------------
- ⚠️ "확인되지 않은 개발자..." 경고창이 추가로 나오는 경우:
  [start_helper.command] 파일에서 마우스 우클릭(또는 Control + 클릭) -> [열기] -> [열기]를 누르시면 즉시 실행됩니다.

- ⚠️ 파이썬(Python3)이 미설치된 상태인 경우:
  터미널 안내에 따라 https://www.python.org/downloads/ 에서 macOS용 Python 3를 설치 후 더블 클릭하시면 됩니다.
