# 인스레드 치트키 by TAKOH

제품 영상 선택·분석·대본 작성·제휴 링크 연결·Threads 게시를 위한 통합 개발 저장소입니다.

## 수집함 연결 및 AI·대본 설정 (3.5.0)

- 다운로드 화면에서 확장 수집함을 제작 레퍼런스와 자동 동기화합니다. 수집·이력 변경 및 창 복귀 시 갱신합니다. localhost와 127.0.0.1을 지원합니다. 확장 갱신 후 기존 제작 페이지를 새로고침해야 브리지가 주입됩니다.
- Chrome ID가 없는 이전 파일도 기본 다운로드 폴더에서 표시하고 제작에 가져옵니다. 다른 위치는 직접 파일 선택 또는 `STUDIO_DOWNLOAD_ROOT`를 사용합니다. 수집 주소만으로 미디어 획득·분석 완료를 표시하지 않습니다.
- Gemini API, Gemini CLI(Google 계정), OpenAI API, Codex CLI(ChatGPT 구독) 중 선택하고 모델 목록·직접 입력을 사용합니다. 공식 CLI 로그인 창과 상태 확인을 제공합니다. 인증은 공식 CLI가 관리하며 프로그램은 인증 파일이나 API 키를 저장하지 않습니다. 모델 목록은 선택 예시이며 계정 접근은 실행 시 확인합니다.
- Codex 구독 경로는 ChatGPT 인증을 확인하며 API 키 방식으로 자동 전환하지 않습니다. CLI는 설치가 필요하고 구독별 한도가 적용됩니다. OpenAI/Codex 분석은 프레임만 사용하며 음성 미분석을 명시합니다. Gemini는 표본 프레임과 처음 최대 60초 음성을 사용합니다.
- 대본 기본 스타일 12종 및 사용자 스타일 등록·수정·삭제를 제공합니다. 사용자 스타일은 도우미 데이터 폴더에 저장하고 선택 당시 지침을 초안에 보존합니다.
- 검증: Python 32개, 수집 동기화·파일 전달·모델 선택 DOM·기존 클릭 검사 통과. 실제 브라우저에서 다운로드 폴더 파일 가져오기, 사용자 스타일 등록, Codex 로그인 상태 확인을 수행했습니다. 외부 모델 생성은 모의 응답 검증이며 실제 모델 생성·Threads 게시·설치된 Chrome의 수집 전달은 실서비스 검증 전입니다.

설치: 새 ZIP의 도우미와 확장을 모두 갱신하고 제작 페이지·원본 사이트를 새로고침하세요. 기존 확장은 제거하지 않고 같은 설치 경로의 파일을 갱신해 수집함을 보존하세요.

## 작업 화면과 실제 파일 연결 (3.4.0)

- 확장 패널과 도우미 스튜디오에 **다운로드 / 콘텐츠 제작·게시** 상단 탭을 제공합니다. 제작은 원본 분석 → 대본·게시문 → 상품·제휴 링크 → Threads 게시의 네 단계로 이동합니다. 탭 이동 자체는 AI 호출이나 게시를 실행하지 않습니다.
- 확장을 로드한 브라우저에서 `http://127.0.0.1:5005/studio/`를 열면 이 다운로더에서 받은 파일을 Chrome 다운로드 ID로 확인합니다. 다운로드 완료·파일 존재·지원 형식이 확인된 항목만 표시하며, **이 파일로 콘텐츠 만들기**는 해당 실제 파일과 원본 주소를 가져옵니다. 파일 이름만 같다고 다른 다운로드와 합치지 않습니다.
- 도우미의 기본 다운로드 폴더(`~/Downloads`) 안에서만 자동 파일 가져오기를 허용합니다. 폴더 밖·삭제된 파일·미완료 항목은 자동 분석하지 않습니다. 다른 저장 위치는 파일 선택으로 불러옵니다. 별도의 다운로드 폴더가 필요한 운영 환경에서는 `STUDIO_DOWNLOAD_ROOT`를 설정할 수 있습니다. 이전 버전의 다운로드 ID 없는 이력도 파일 선택을 사용합니다.
- Shorts Studio의 `script_planning_engine.py` JSON 처리와 `scenario_quality.py` 근거 중심 검수 방식을 참고해 Threads용 독립 `studio_writing.py`로 적용했습니다. 사용 장면 소개·질문과 답·불편과 해결 스타일을 선택하고, 확인되지 않은 제품·가격·효과·실사용 후기를 만들어내지 않도록 지시합니다. 과장·참여 유도·실사용 단정 문구는 검토 사항으로 표시하며 자동 사실 검증을 했다고 표시하지 않습니다.
- AI 성공 응답의 본문과 사용량 메타데이터는 분석/초안 검증 전에 해당 작업 폴더의 `analysis-response-*.json`, `draft-response-*.json`으로 보존합니다. 키·요청 헤더·인증 정보는 보존하지 않습니다. 오류가 발생해도 기존 분석을 유지하고 자동 재호출하지 않습니다.

배포본: `downloader/InThread_Cheatkey_TAKOH_v3.4.0.zip`. 새 도우미를 실행하고 새 `TAKOH_Extension` 폴더를 로드/새로고침한 뒤 기존 사이트와 스튜디오 페이지도 새로고침합니다. Shorts Studio 설치나 실행은 필요하지 않습니다.

검증은 실제 FFmpeg와 독립 EXE의 파일 가져오기·SHA256·음성·프레임 처리, 브라우저 탭/단계 전환·영상 준비 상태, 모의 Chrome 다운로드/API 응답을 사용하는 회귀 검사로 구분했습니다. 실제 설치된 확장의 Chrome 다운로드 전달과 실제 AI 품질·계정 게시 결과는 아직 별도 검증이 필요합니다.

## 기존 다운로더 안으로 수집 기능 통합 (3.3.1)

`downloader/`가 사용자용 단일 확장입니다. 기존 다운로드 버튼 옆의 **수집** → 같은 확장 패널의 **콘텐츠 보관함** → **분석·상품 찾기**로 도우미 내 스튜디오를 엽니다. 별도 레퍼런스 확장을 설치할 필요가 없습니다. 수집은 선택한 미디어의 주소를 보관하며 다운로드·분석·게시 완료로 기록하지 않습니다. 다른 게시물과 합쳐지는 것을 막기 위해 고유 게시물 주소가 없으면 직접 미디어 주소를 기준으로 보관합니다. blob만 있고 게시물 주소를 확인할 수 없으면 수집 실패로 표시합니다.

기존 `reference-studio/`는 참고용 개발 소스로 남습니다. 기존 확장의 예약 대기열·설정 자동 이전은 구현 전입니다. 실제 다운로드한 파일은 스튜디오에서 선택해야 하며 다운로드 이력의 파일 자동 전달은 다음 통합 단계입니다.

배포: `downloader/build_helper.py`로 최신 EXE를 만든 후 `downloader/build.py`로 `InThread_Cheatkey_TAKOH_v3.3.1.zip`을 생성합니다. ZIP에는 기존 다운로드 기능과 보관함을 갖춘 `TAKOH_Extension`, 분석·검색·게시 기능을 내장한 `TAKOH_Helper`가 함께 들어갑니다.

## 원본 기반 검색과 보관함 연결 (3.3.0)

- 원본 이미지(10MB 이하)를 선택하거나 영상에서 추출한 6개 프레임 중 하나를 선택해 Google Lens 검색을 실행합니다. 실제 선택 이미지 파일을 SerpAPI `/image`에 업로드하고 반환된 `image_id`로 검색합니다. 별도의 이미지 호스팅 주소가 필요하지 않습니다.
- `products`, `exact_matches`, `visual_matches` 검색을 구분하고 원본과 후보 이미지를 나란히 표시합니다. 상품 후보는 상품 입력으로 전달하고 선택 근거 프레임/이미지 해시를 함께 저장합니다. 콘텐츠 후보는 원본 링크로 확인합니다. 동일 이미지 결과도 영상 전체가 같은 것으로 확정하지 않습니다.
- 레퍼런스 확장의 팝업 보관함과 대시보드에서 수집한 게시물을 스튜디오로 전달할 수 있습니다. 공개 본문·원본 주소·이미지/영상 URL만 전달하며 인증 데이터는 전달하지 않습니다. 스튜디오에서 추가 버튼을 눌러 저장한 뒤 원본 주소를 작업에 적용하고 실제 미디어 파일을 선택합니다. URL 수집과 실제 파일 확보/분석은 별도 단계입니다.
- 선택한 이미지도 분석·초안·상품 연결과 게시 준비를 지원합니다. 공식 자동 게시에서 이미지 작업은 `IMAGE` 컨테이너를 사용합니다. 공개 이미지 URL은 여전히 필요합니다.

검색을 누를 때 이미지가 외부 서비스로 전송되며 요금이 발생할 수 있습니다. 실제 키로 검색 품질을 확인하지 않았습니다. [SerpAPI 공식 이미지 업로드 경로](https://serpapi.com/google-lens-upload-an-image)

3.3.0의 별도 레퍼런스 확장 연결도 유지하지만 3.3.1부터 기본 수집은 다운로더 안에서 제공합니다. 기존 예약 대기열·설정 자동 이전과 설치된 인스레드_치트 폴더 변경은 하지 않습니다.

## 스튜디오 1단계

도우미 실행 후 `http://127.0.0.1:5005/studio/`를 열거나 확장 팝업의 스튜디오 버튼을 누릅니다.

1. 300MB·10분 이하의 로컬 영상을 선택합니다. 실제 파일의 길이·해상도·음성 트랙, SHA-256, 시각별 프레임 6개를 저장합니다.
2. Gemini API 키와 사용 가능한 모델을 입력하고 분석을 실행합니다. 영상 전체에서 고르게 뽑은 프레임 6개와 처음 최대 60초의 음성만 전송합니다. 전체 영상의 모든 장면을 분석한 것으로 표시하지 않습니다.
3. 상품 URL과 본인 계정에서 직접 발급한 제휴 링크를 등록합니다. 링크 귀속은 사용자 확인이며 제휴사 API 검증이 아닙니다.
4. 분석의 관찰 근거를 전달해 대본·Threads 본문 초안을 만들고 편집합니다. 제휴사의 공식 고지 문구를 입력해 광고 댓글을 준비합니다.
5. 본문·댓글을 복사하고 영상 파일을 저장해 Threads에서 직접 첨부·게시합니다. 복사하거나 Threads를 여는 것으로 게시 완료를 기록하지 않습니다.

키는 작업 JSON에 저장하지 않습니다. 서버 환경변수 `GEMINI_API_KEY`도 지원합니다. AI 요청은 사용자가 분석·초안 버튼을 눌렀을 때 실행되며 비용이 발생할 수 있습니다. API 한도 오류에 자동 재요청하지 않습니다. REST 입력은 [Google 공식 generateContent API](https://ai.google.dev/api/generate-content)를 사용합니다.

작업 기본 저장소는 Windows `%LOCALAPPDATA%/ONEWS/studio`입니다. `STUDIO_DATA_DIR`로 분리할 수 있습니다. 원본 영상·추출 음성·프레임·분석·초안이 컴퓨터에 유지됩니다.

## 스튜디오 2단계

- **SerpAPI 검색**: 분석 검색어 또는 직접 입력한 검색어로 선택 서비스의 상품 페이지 후보를 검색하고 상품 입력 칸에 연결합니다. 가격/동일 제품/제휴 귀속이 검증된 결과로 표시하지 않습니다. 검색 버튼에서만 API를 호출합니다.
- **쿠팡 공식 발급**: 일반 쿠팡 상품을 저장한 후 쿠팡파트너스 API Access/Secret Key로 딥링크를 발급합니다. 응답의 원본 URL 일치와 발급 URL을 확인하고 `coupang_api` 발급 경로를 기록합니다. 실제 계정 정산 귀속은 별도 확인해야 합니다.
- **Threads 자동 게시**: 게시·댓글 권한을 갖춘 액세스 토큰으로 `/me`에서 계정을 확인합니다. 공개 HTTPS 영상 URL을 입력하고 선택한 영상과 같은지 확인한 뒤 게시를 실행합니다. 영상 컨테이너 처리 완료 → 본문 발행/내용 확인 → 광고 댓글 발행/부모 관계 확인을 순서대로 수행합니다.
- 처리 중에는 화면에서 5초 간격으로 진행 확인을 최대 24회 수행합니다. 계속 처리 중이면 버튼으로 이어갑니다. 본문 성공·댓글 실패는 부분 성공으로 기록하고 본문을 다시 올리지 않습니다. 네트워크/서버 오류 등으로 발행 결과가 불확실하면 중복 방지를 위해 자동 재발행을 차단합니다. 실제로 발행된 API 게시 ID를 입력해 계정/내용/부모 관계를 확인하고 복구할 수 있습니다.
- 자동 게시가 시작된 작업의 본문·상품은 잠급니다. 키와 토큰은 저장하지 않으며 `SERPAPI_KEY`, `COUPANG_ACCESS_KEY`, `COUPANG_SECRET_KEY`, `THREADS_ACCESS_TOKEN` 환경변수도 지원합니다. 쿠팡 Access Key 자체 대신 단방향 계정 지문만 보관합니다.

남은 개발: 다운로드 이력에서 바로 영상 선택, Amazon·네이버·토스의 공식 발급 연결, Meta OAuth 로그인, 로컬 영상의 공개 저장소 업로드. 현재 Amazon·네이버·토스는 직접 발급한 링크 등록 방식입니다. 토큰 입력을 OAuth 로그인이라고 표시하지 않으며, 로컬 영상만 선택했다고 자동 게시가 준비된 것으로 표시하지 않습니다.

공식 자료: [SerpAPI 검색 결과](https://serpapi.com/organic-results), [쿠팡 파트너스 API 가이드](https://coupang-partners.tistory.com/entry/쿠팡-파트너스-API-가이드-1-가이드), [Meta Threads API](https://www.postman.com/meta/threads/documentation/dht3nzz/threads-api).

검증: `python -m unittest test_studio.py test_studio_integrations.py test_helper_regressions.py` (`STUDIO_TEST_FFMPEG`에 FFmpeg 경로 설정), `node test_studio_ui.js` (jsdom 필요). 외부 API 응답은 테스트에서 모의 응답을 사용합니다. 실제 계정의 검색·제휴 발급·게시 결과, AI 품질과 EXE 배포는 별도 검증이 필요합니다.

## 개발

확장: Chrome 확장 관리에서 `downloader/`를 압축해제 확장으로 로드합니다.

도우미: Python 3.11 이상에서 `cd downloader` 후 가상환경에 `pip install -r requirements.txt`, `python app.py`.
로컬 주소는 `http://127.0.0.1:5005`입니다.

레퍼런스 화면: `cd reference-studio`, `npm ci`, `npm run dev`. 배포 빌드는 `npm run build`.

다운로더 DOM 테스트는 jsdom을 `downloader/.test-tools`에 설치한 뒤 실행합니다:
`npm install --prefix .test-tools --no-audit --no-fund jsdom@30.1.2`
`node test_overlay_positions.js` 등 제공된 회귀 테스트를 실행합니다.
Python 회귀 테스트: `python -m unittest test_helper_regressions.py`.

## 배포 파일

EXE, FFmpeg/aria2c 바이너리, 이전 배포 ZIP, 수집 영상, 브라우저 프로필과 쿠키는 소스 Git 이력에 포함하지 않습니다. Windows 배포 시 공식 도구 바이너리를 준비하고 `build_helper.py`로 도우미를 만든 다음 `build.py`를 실행합니다. 소스 업로드만으로 Windows 통합 배포 ZIP이 만들어지지는 않습니다.

API 키·액세스 토큰·제휴 비밀키는 커밋하지 않습니다.
